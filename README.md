# Projeto Sistema de Gerenciamento de Registros

Este projeto consiste na criação de um sistema capaz de administrar as informações de uma Concessionária. O programa roda localmente, com uma base de dados que pode ou não ser compartilhada. No caso da base de dados ainda não existir no diretório da aplicação, o sistema cria uma nova. 

As informações gerenciadas pelo sistema baseiam-se nas características, comuns e específicas, do maquinário vendido pela concessionária, isto é, Motos, Carros, Caminhões, Helicópteros e Barcos.

As operações realizadas por esse sistema são de (1) Criação de registro, (2) Busca de registro, (3) Edição de registro e (4) Remoção de registro.
Vale ressaltar que os registros ficam armazenados em um documento utilizado pela aplicação. Portanto, todas as operações mencionadas atuam diretamente nesse documento.
