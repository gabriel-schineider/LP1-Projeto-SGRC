# Projeto Sistema de Gerenciamento de Registros

Este projeto consiste na criação de um modelo capaz de administrar as informações sobre as quais uma Concessionária poderia querer ter controle. O programa roda 
localmente, com uma base de dados que pode ou não ser compartilhada. No caso de uma base de dados não já existir no diretório da aplicação, o sistema cria uma nova. 

As informações gerenciadas pelo sistema baseiam-se no maquinário vendido pela concessionária, isto é, Motos, Carros, Barcos, Helicópteros, Bicicletas e Skates.
De preço e cor a características específicas de cada máquina, como pressão de pneus ou altitude máxima, são administradas. 

As operações realizadas por esse sistema são de (1) Criação de registro, (2) Busca de registro, (3) Edição de registro e (4) Remoção de registro.
Vale ressaltar que os registros ficam armazenados em um documento utilizado pela aplicação. Portanto, todas as operações mencionadas atuam diretamente nesse documento.
